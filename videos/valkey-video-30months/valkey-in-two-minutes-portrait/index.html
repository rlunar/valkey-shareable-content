Memory access is faster than disk access.
Valkey keeps working data in memory,
with optional disk persistence.
Valkey is an open source (BSD)
high-performance key/value datastore that supports
a variety of workloads such as caching,
message queues,
and can act as a primary database.
The project is backed by the
Linux Foundation,
ensuring it will remain open source forever.
Start with a key and a value.
SET stores it.
GET reads it back.
Cache-aside is a common starting point.
Your app checks Valkey first.
On a miss,
it reads the database and caches
the result with an expiry.
The next hit skips the database.

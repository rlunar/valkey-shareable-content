      Operational boundaries

      Separate disposable caches from important operational state. Atomic commands do not guarantee durability, exactly-once side effects, or cross-system transactions. Replication is asynchronous by default; WAIT does not turn Valkey into a consensus system. Application logic owns source retrieval, retries, authorization and reuse decisions. Key prefixes are not resource isolation.

These local SVGs are used only to identify the open source projects discussed in the keynote.

- `linux.svg` — Linux mark from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/linux.svg) (CC0-1.0 collection; Linux trademark belongs to Linus Torvalds).
- `kubernetes.svg` — Kubernetes mark from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/kubernetes.svg), derived from official Kubernetes artwork. Kubernetes is a registered trademark of The Linux Foundation.
- `opensearch.svg` — icon extracted from the [official OpenSearch project artwork](https://github.com/opensearch-project/project-website/blob/main/assets/brand/SVG/Logo/opensearch_logo_default.svg).
- `pytorch.svg` — [official PyTorch documentation logo](https://github.com/pytorch/pytorch/blob/main/docs/source/_static/img/pytorch-logo-dark.svg).
- `vllm.svg` — [official vLLM media kit](https://github.com/vllm-project/media-kit/blob/main/vLLM-Full-Logo.svg).
- `strands.svg` — [official Strands Agents artwork](https://github.com/strands-agents/harness-sdk/blob/main/site/src/assets/logo-auto.svg).
- `postgresql.svg`, `linux-foundation.svg`, and the other pre-existing files retain their original project provenance.

## Technical Steering Committee logos (`tsc/`)

Used on the “What is Valkey” slide to show the eight companies whose maintainers form the Valkey Technical Steering Committee, per `MAINTAINERS.md` in `valkey-io/valkey`. Seven affiliations use permitted company logos; Apple® is rendered as plain text.

- AWS, Google Cloud, Oracle, Ericsson, and Percona are not copied here; the slide imports them from this repository’s `ValkeyDesignSystem/assets/participants/` (the same artwork valkey.io shows on its participants page) through the `@valkey-assets` Vite alias.
- `tencent-cloud.svg` and `alibaba-cloud.png` — participant artwork as shown on [valkey.io/participants](https://valkey.io/participants/), taken from the shared Valkey asset library (`shared-assets/valkey`, day11 landscape capture).
- Apple® is intentionally displayed as text; this presentation does not have permission to use the Apple logo.
